# DTF Semitonos

Prepara diseños para imprimir en DTF, todo dentro del navegador (Chrome o Edge):
mejorar la calidad con IA, quitar el fondo, semitonos para camiseta blanca o negra
y PNG final sin semitransparencias, con los DPI grabados.

La imagen no sale de tu computadora: la IA corre en tu propia GPU.
Los modelos se bajan la primera vez que usas cada botón y quedan guardados.

Hecho por Lowis Mendoza.

Usa onnxruntime-web (MIT), Real-ESRGAN (BSD-3), BiRefNet (MIT) e ISNet (Apache-2.0).
